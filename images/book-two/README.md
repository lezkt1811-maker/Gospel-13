# Book Two images — *The Gospel of Eve and Lilith: Feminine Earth Grid*

Upload this book's images into **this folder** with these exact names:

| File name | What it is |
|---|---|
| `cover.jpg` | The book cover |
| `art-01.jpg` | Illustration 1 |
| `art-02.jpg` | Illustration 2 |
| … | … |
| `art-26.jpg` | Illustration 26 |

- Always two digits: `art-01`, not `art-1`.
- All lowercase, with a dash.
- Images appear on the website automatically. Missing numbers are simply skipped.
- If your files are `.png`, change `artExtension` to `"png"` under `bookTwo` in `config.js`.
- For fast loading on phones, aim for about **1600 pixels** on the longest side and under **600 KB** each.
- Each artwork gets its own permanent page: `art.html?art=two-01`, `art.html?art=two-02` …
